# Superseded RFCs

This directory contains formerly accepted decisions replaced by later accepted
RFCs. Entry requires links to the replacement, the effective transition, and
any migration or compatibility interval. Supersession preserves the historical
reasoning that governed older doctrine versions.

Superseded RFCs are immutable decision history except for factual annotation and
link repair. They must not be edited to resemble the replacement. Consumers use
the active doctrine and newest accepted decision.

An RFC enters this directory only after the replacement is accepted and its
implementation plan addresses affected rule IDs, manifests, generated packs,
references, and stored/protocol compatibility. It has no normal exit.

Relationship to doctrine status: the implementation may mark a doctrine
superseded and set `superseded_by`, or may replace only one repository policy.
The RFC directory alone does not change manifest status.
