# RUST-DOC-0004 provenance

> [!NOTE]
> Informative. Provenance explains where an idea came from and how this corpus treated it. It
> creates no obligation. Those live in
> [Concurrency and Async Correctness](../../doctrines/0004-concurrency-and-async/README.md),
> with stable rule identifiers.

Files: [source notes](source-notes.md) and [attribution](attribution.md). What each one records is
described once, in [the provenance index](../README.md), rather than repeated per package.

> [!TIP]
> A source can explain language or protocol mechanics without determining repository policy,
> severity, waiver, or review structure. Where the two differ, the doctrine governs.
