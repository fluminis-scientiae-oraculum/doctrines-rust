# RUST-DOC-0005 attribution

PostgreSQL is cited as a concrete primary product source, not a universal
database specification. Applications using another database must substitute
its official constraints, isolation, locking, enum, durability, and failure
documentation.

Serde and Rust standard-library material is linked rather than reproduced.
Quarantine, migration evidence, guarantee ledgers, and review severity are
repository governance.

The package does not claim exhaustive database research or define one universal
commit-ambiguity classifier. Driver and topology behavior must be verified for
the deployed system.
